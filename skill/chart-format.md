# Monument Rhythm chart format

Each song lives in its own subfolder under the library root the game points at.

```
songs/
  sand-procession/
    audio.ogg          # any browser-playable file: ogg, mp3, wav, m4a, flac
    chart.json         # play file generated by this skill
  ivory-steps/
    audio.mp3
    chart.json
```

The game never reads files outside those subfolders. Cover images are optional (`cover.jpg` / `cover.png`) and unused by the prototype HUD.

## chart.json

```json
{
  "version": 1,
  "title": "Sand Procession",
  "artist": "Prototype",
  "audio": "audio.ogg",
  "duration": 32.0,
  "bpm": 96,
  "offset": 0.0,
  "lanes": 4,
  "difficulty": "normal",
  "preview": 8.0,
  "notes": [
    { "t": 1.25, "lane": 0, "type": "tap" },
    { "t": 4.00, "lane": 2, "type": "hold", "end": 5.50 }
  ]
}
```

Rules the game engine assumes:

- `t` is seconds from audio time zero.
- `lane` is `0 .. lanes-1` left to right.
- Notes must be sorted by `t`.
- Two notes may share the same `t` only if they occupy different lanes (chords).
- Hold `end` must be greater than `t` by at least 0.18 s.
- `offset` shifts every note at load time: `t_effective = t + offset`.

## Judgement windows (engine)

| Grade   | Window        | Score |
|---------|---------------|-------|
| Perfect | ±0.045 s      | 300   |
| Great   | ±0.090 s      | 200   |
| Good    | ±0.140 s      | 100   |
| Miss    | beyond / skip | 0     |

Holds award a second tap-grade at `end` if the key stays down.

## Difficulty presets used by `make_chart.py`

| Preset | Onset percentile keep | Min gap | Holds | Chords |
|--------|-----------------------|---------|-------|--------|
| easy   | top 38%               | 0.22 s  | rare  | none   |
| normal | top 58%               | 0.14 s  | some  | sparse |
| hard   | top 78%               | 0.09 s  | more  | frequent |
